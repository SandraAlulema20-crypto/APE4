# APE4
Programacion Orientada a Objetos
Guía APE 4 - Programación Orientada a Objetos en Java

📌 Descripción

Este repositorio contiene los cinco ejercicios de la Guía APE 4, desarrollados en Java para practicar los conceptos básicos de la programación orientada a objetos.

🎯 Objetivo

Aplicar clases, objetos, atributos, referencias, estructuras repetitivas y condiciones mediante ejercicios prácticos.

📚 Ejercicios

1. Estudiante y promedio

* Crear cinco estudiantes con sus respectivas notas.
* Calcular el promedio de cada estudiante.
* Determinar si está aprobado, en supletorio o reprobado.
* Contar el número de estudiantes aprobados.

2. Producto e inventario

* Crear cuatro productos con nombre, precio y stock.
* Simular la venta de tres unidades de dos productos.
* Identificar los productos que necesitan reposición.
* Calcular el valor total del inventario.

3. Mascota y referencias de objetos

* Crear tres mascotas con nombre, especie, edad y peso.
* Mostrar los datos de cada mascota.
* Identificar las mascotas que necesitan revisión de peso.
* Comprobar cómo dos variables pueden referirse al mismo objeto.

4. Cuenta bancaria

* Crear dos cuentas con diferentes saldos.
* Depositar 50 unidades monetarias cada mes.
* Utilizar un ciclo while hasta alcanzar un saldo de 500.
* Mostrar los saldos y la cantidad de meses necesarios.

5. Biblioteca y préstamo de libros

* Crear cuatro libros y dos socios.
* Registrar los préstamos de libros.
* Mostrar la disponibilidad de cada libro.
* Contar los libros disponibles y mostrar los libros prestados por cada socio.

🛠️ Tecnologías utilizadas

* Lenguaje: Java
* Conceptos: clases, objetos, atributos, referencias, condicionales y ciclos.
* Herramientas: JDK y un editor de código compatible con Java.

▶️ Cómo ejecutar los ejercicios

1. Instalar el JDK de Java.
2. Descargar o clonar este repositorio.
3. Abrir el ejercicio que se desea ejecutar.
4. Compilar el archivo correspondiente desde la terminal:

javac Estudiante.java

5. Ejecutar el programa:

java Estudiante

Repetir el procedimiento con la clase principal de cada ejercicio.
